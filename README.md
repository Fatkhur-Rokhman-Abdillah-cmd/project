# BrightPath Academy Website

A responsive multi-page static website built with HTML, CSS, and JavaScript.

## Pages
- `index.html` — home page
- `about.html` — about page
- `programs.html` — programs page
- `contact.html` — contact page with client-side validation

## Run locally
Open `index.html` in a browser, or start a simple local server from this folder:

```bash
python -m http.server 8000
```

Then visit: `http://localhost:8000`

## Features
- Responsive layout
- Dark mode toggle
- Contact form validation
- Clean, modern styling
